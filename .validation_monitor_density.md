## 🎨 Severity Mapping (Edge Case Compliance)

### Strict Threshold Logic
```javascript
function getSeverityClass(probability) {
  if (prob > 0.65) return 'row-alert-high';   // ALERT
  if (prob > 0.55) return 'row-alert-medium'; // INFO
  return 'row-alert-low';                      // TICK
}
```

### Edge Case Tests
- ✅ `prob = 0.65` → `row-alert-medium` (INFO, NOT ALERT)
- ✅ `prob = 0.66` → `row-alert-high` (ALERT)
- ✅ `prob = 0.55` → `row-alert-low` (TICK, NOT INFO)
- ✅ `prob = 0.56` → `row-alert-medium` (INFO)

## ✅ Formatting Functions

### Time Formatting
```javascript
formatTime(iso) → "HH:MM:SS" (UTC, 2-digit padding)
// Example: "2026-02-24T15:30:42Z" → "15:30:42"
```

### Price Formatting
```javascript
formatPrice(float) → "XX.XX" (always 2 decimals)
// Example: 95.6 → "95.60"
```

### Probability Formatting
```javascript
formatProbability(float) → "XX.XX" (2 decimals, no % symbol in value)
// Example: 0.7234 → "72.34"
```

### Signal Normalization
```javascript
ml.signal.toUpperCase() → "COMPRA" | "VENDA" | "HOLD"
```

### Status Icons
```javascript
getStatusIcon(valid) → "✅" (valid) | "⚠️" (blocked)
```
